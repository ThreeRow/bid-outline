# 提示词索引

0.12.0默认文本流程使用[text/](text/README.md)内的N任务占位模板，最终设计需用户参与。任务渲染见`model/text_tasks.py`，普通文本结果跳过旧字段解析。下文描述保留作历史回归的P任务模板。

任务模板采用“序号_功能名称.txt”，例如 `P01_整块相关性判断.txt`、`P04-B_技术评审要求提取.txt`、`P14_已提取要求覆盖检查.txt`。

完整编号与功能名称映射维护于 `model/task_specs.py` 的 `TASK_NAMES`。程序和审计仍使用稳定任务编号P01、P04-B等；文件更名不改变任务身份或提示词正文。

`common/` 保存公共系统规则、编排规则、ABC提取共用规则及记录格式。任务文件已展开需要的共用片段，实际请求不依赖模型知道外部模板编号。修改共用业务规则时应同步相应任务文件并核对渲染结果。

v0.8.0：P01—P18各模板包含独立任务背景、步骤与必要定义，不依赖模型记忆。输入默认使用readable-v1；legacy-json显式保留作对照。第一轮保留原输出契约隔离实验；现显式compact-v1可对已评测任务简化标记，全部字段语义仍按严格契约校验。详见docs/19_独立任务提示与可读输入.md。
