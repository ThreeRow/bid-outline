# 文本流程提示词

当前应用0.14.1，模板版本`separated-material-provider-2`，flow为`collaborative-directory-4`。14份业务模板按角色、背景、当前任务、返回内容组织，已移除`{context}`插入点。占位符样式出现在招标原文中时保持原样。

`TextMaterial`的body/context/supplement/feedback分别表示负责正文、位置元数据、必要来源补充和上次反馈。所有资料都在任务说明后的`---`分隔线之后，不把表格或技术参数插进背景与任务之间。角色和任务语义在两种provider间共用：

- OpenAI：system为角色，user为任务说明、分隔线和资料。
- train：将角色、任务说明、分隔线和资料形成一份query，不添加system/user文字标签。预算、wire和input.md共用实际文本。

N01不重复附带本次寻找目标，E00/E02的实际目标属于输入说明。来源元数据、正文和补充原文在资料区按顺序呈现；修正反馈也属于数据，通用修正任务说明在分隔线前。自动推断的带行列坐标的表格leader不再整体附入，合法多行条件完整保留，显式共同条件与必要表头完整保留，原始推断记录仍在source chunk审计。

| 任务 | 输入与输出 |
|---|---|
| E01 | 根据真实章节目录定位A/B/C候选位置 |
| E00 | 根据实际目标及局部资料返回保留/排除/待核 |
| E02 | 根据实际目标和完整块返回起止句及中间锚点 |
| N01-A | 从编制原文直接生成缩进目录草稿 |
| N01-B/C | 沿原句整理评审要求/技术要求 |
| E03-A/B/C | 合并A目录草稿/统一整理B、C要求文本 |
| N02-A | 将A锚定回取原文转为目录，direct不重复调用 |
| N02-B | 显式展开内容列项及实际评价维度 |
| N03/N04/N05 | 融合目录、按C补充、最终润色 |

目录以缩进表达层级。E00保持三态；其余任务精确整答“无”标记no_content，原始回答保留，空答仍失败。已有草稿后继无内容时保留草稿及问题。

9000感知阈值、4000正文拆分目标及有限整合继续复用既有能力。模板/角色/输入结构变化需新run，旧审计不改写。395项离线回归通过（18.90秒），本轮未新增真实模型调用；S21两种接口输入预览在reviews/prompt_boundaries_20261109_v0141，不能当模型质量验收。
