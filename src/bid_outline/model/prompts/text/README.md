# 新文本流程提示词（占位版本）

这些提示词为0.12.0文本流程提供可运行占位，最终设计需用户参与，尚未进行真实模型质量验收。

- N01-A/B/C：在程序已定位的候选范围内整理内容。
- N02-A：根据A整理文本生成格式目录。
- N02-B：显式展开评审列项及完整性、先进性等评价维度。
- N03：融合A/B及分批目录草稿。
- N04：根据C补充目录，也支持只有C提供明确目录依据的情况。
- N05：去除过程分析、统一目录表达，不删除评价维度。

中间输出是普通文本，不要求节点ID、固定字段、记录标记或JSON。只有最后一步要求输出可读目录，未引入逐节点解析。程序仅验证非空正文及已知结束状态，不据此声称结果语义正确或完整。

修改这些模板会改变执行指纹。与配置、代码或流程版本不匹配的旧run不能继续作为同一次运行使用。
